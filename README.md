# Smart Organizer

O Smart Organizer é um software desktop desenvolvido em Python que organiza automaticamente arquivos de uma pasta, separando por tipo e por ano. O sistema possui interface gráfica e cria automaticamente as pastas, facilitando a organização de arquivos no computador.

## Funcionalidades
- Interface gráfica
- Organização automática por tipo de arquivo
- Organização por ano
- Suporte a múltiplos formatos
- Criação automática de pastas
- Contador de arquivos organizados

## Tecnologias utilizadas
- Python
- Tkinter
- OS
- Shutil
- Datetime

## Como executar o projeto
1. Clone o repositório:
   git clone https://github.com/phguerrra/Smart-Organizer.git

2. Entre na pasta do projeto:
   cd Smart-Organizer

3. Execute o programa:
   python interface.py

## Estrutura do projeto
- interface.py → Interface gráfica
- organizador.py → Lógica de organização dos arquivos
