# Smart Organizer

O Smart Organizer é um software desenvolvido em Python que organiza automaticamente arquivos de uma pasta, separando por tipo e por ano.

## Funcionalidades
- Interface gráfica
- Organização por tipo de arquivo
- Organização por ano
- Suporte a vários formatos
- Criação automática de pastas

## Tecnologias
- Python
- Tkinter
- OS
- Shutil

## Como executar
python interface.py
